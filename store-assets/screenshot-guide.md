# Screenshot Guide for Chrome Web Store

Chrome Web Store requires 1-5 screenshots at 1280x800 or 640x400 pixels.

## Required Screenshots

### 1. Popup — Shortening a URL
- Navigate to any website (e.g., your own site)
- Click the QuickYOURLS extension icon
- Show the popup with a URL ready to shorten, or just after shortening (with the green result field visible)
- Capture at 1280x800

### 2. Options — Server Configuration
- Open the extension options page
- Show at least one server configured with a name and URL filled in
- Show the "Test Connection" result as "Connected!"
- Capture at 1280x800

### 3. Context Menu
- Right-click on any link on a webpage
- Show the "Shorten This Link" context menu item highlighted
- Capture at 1280x800

### 4. Multi-Server Dropdown (optional but recommended)
- Configure 2+ servers in options
- Open the popup — show the server selector dropdown expanded
- Capture at 1280x800

## How to Capture

### Windows
- Use `Win + Shift + S` (Snipping Tool) or a browser extension
- Resize browser window to exactly 1280x800 before capturing

### Tips
- Use a clean browser profile (no distracting bookmarks bar)
- Use a professional-looking website in the background
- Ensure the popup/options are fully visible and not cut off
- Save as PNG for best quality
